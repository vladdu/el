# EL

A heuristic DC bias circuit analyzer after Sussman and Stallman, MIT AI Memo 328 (1975). It solves circuits by local one-step deductions, guided by the designer's intent, and can explain every result.

```sh
uv run el
```

- [Using EL](docs/usage.md): input syntax, output format, and how to run analyses.
- [Glossary](GLOSSARY.md): domain terms.
- [ADRs](docs/adr/): design decisions.
